Introduction

What guaitaCalc is

guaitaCalc combines a calculator (algebraic and RPN) with 63 formulas grouped in collapsible chapters: Structures (24), Economics and accounting (20), Urban planning (10), CO₂ and energy (5) and Other (4), plus an equation solver and a function plotter. It is a preliminary sizing tool.

Results do not replace calculation and code verification by a qualified professional.

Installation & PWA

Installing as an app (PWA)

You can open the app directly (guaitaCalc_0.6.html) or serve it from an HTTP(S) server such as GitHub Pages. In the latter case it works as a PWA: installable and usable offline.

  1. Open the app from the published page (https).
  2. Use File › Install the app (shown when the browser allows it) or the browser’s “Install / Add to home screen”.
  3. Launch it from its icon: it runs full-screen and offline.
Opening the file from disk (file://) works too, but it cannot be installed and no offline cache is registered.

Calculator

Calculator
  • Mode: Calculator › Algebraic or RPN.
  • Angle unit: DEG, RAD or GRAD.
  • Function keypad: Basic, Scientific or Advanced (sin, cos, tan, log, n!, eˣ…).
  • Constants…: physical and mathematical constants.
  • Memory row and History tape with optional Σ subtotal; the tape can be copied or exported as text.

The function argument separator is ; and scientific notation is typed with E. The evaluator is custom and never uses eval.

Formulas

Formulas and working tools

Open a formula from the Formulas menu, from the list (Formulas tab on mobile) or with search (Ctrl+K). The CTE by DB chapter groups formulas by Spanish building-code document.

Units
Tap the unit of a field or result to change it.
Trace
Shows the step-by-step substitution; export to Markdown or LaTeX.
Sensitivity
Varies one variable and shows the result; can be sent to the plotter.
Notebook
Save calculations (“Save to notebook”); export it as Markdown or JSON.
Favourites
Mark frequently used formulas with ★.
Output
Copy results, export Markdown or print / PDF.

Each formula shows its reference (code and edition), a tip (💡) and, where needed, its limitations (in the app and in exports).

CO₂ factors

Importing CO₂ factors

Menu File › Import CO₂ factors (CSV, BC3)…. Load your own factors (e.g. ÖKOBAUDAT or ITeC) and use them in the CO₂ formulas. Delete imported factors removes them. The repository includes a sample, exemple_factors_CO2.csv.

Math tools

Solver and plotter
  • Equation solver: equation roots (bisection/Newton/secant), linear systems, polynomials and solving a formula for one variable.
  • Function plotter: up to four functions, zoom, roots and extrema, and export. Trigonometric functions are plotted in radians.

Look & projector

Look, projector and sound

View menu: skins (Guaita, LCD, amber, flat and more), light theme (Guaita skin), Projector mode (F8, with A+/A− font size), key sounds with several profiles, volume and haptics, and Language (Català / English).

Privacy

Privacy

All calculation happens locally in your browser. No servers, accounts or telemetry, and no external resources are loaded (fonts are embedded). History, notebook and preferences are stored in your device’s localStorage.

FAQ

FAQ
Can I use it offline?

Yes. It is a single HTML file and, as a PWA, it is cached on the device.

Why does the result differ from my own calculation?

Check the formula’s reference and limitations: they state the code edition and simplifications.

How do I change the language?

View › Language.

Where is my data stored?

Only in your browser (localStorage). Export the notebook if you want a copy.

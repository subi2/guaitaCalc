# Contribuir · Contributing

**Català.** Les contribucions són benvingudes (errors, millores, traduccions, revisió de valors normatius amb la font oficial). Obre un *Issue* abans de canvis grans. Cada fórmula ha d'indicar la referència, les limitacions i tenir una prova numèrica. Les contribucions s'ofereixen sota **AGPL-3.0-only**.

**English.** Contributions are welcome (bugs, improvements, translations, checking regulatory values against the official source). Open an Issue before large changes. Every formula must state its reference and limitations and have a numeric test. Contributions are licensed under **AGPL-3.0-only**.
